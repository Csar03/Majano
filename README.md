# Restaurante Majano Website

Este es un sitio web simple para el restaurante Majano. Es responsive, priorizando móvil.

## Estructura
- `index.html`: Página principal con opciones.
- `css/styles.css`: Estilos para diseño y responsividad.
- `js/script.js`: JavaScript básico (expándelo para funcionalidades).
- `pages/`: Páginas adicionales (carta, reserva, fotos).
- `menu/`: Páginas para cada sección del menú.
- `footer/`: Footer dinámico.
- `resources/`: Imágenes y recursos.

## Cómo usar
1. Abre `index.html` en un navegador.
2. Navega usando los enlaces.
3. Para agregar platos, edita los archivos en `menu/`.
4. Los iconos de alérgenos son bolitas de colores (rojo para gluten, amarillo para lácteos, etc.).
